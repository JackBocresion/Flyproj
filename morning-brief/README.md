# Morning briefs

Overnight research briefs. Each edition has a readable brief, the raw research behind it, and a note on how it was made.

Layout of an edition folder:

- `BRIEF.md`: the brief (front matter, Part 1, Part 2, process notes)
- `research/`: one raw file per research slice, each ending in an independent verification log
- `sections/`: the parts as written and grounding-checked, before assembly
- `figures/`: diagrams used in the brief
- `site/`: the HTML build published as the web version
